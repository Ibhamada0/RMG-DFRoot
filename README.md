# RMG — Original DFRoot foundation

This repository is an independent derivative of [diabl0w/DFRoot](https://github.com/diabl0w/DFRoot), customized with the RMG visual identity, six selectable themes and a user-confirmed, offline SU Manager installer.

**Provenance:** This repository was created empty rather than with GitHub's Fork button, so it is not a GitHub-network fork. The original source copyright and credits must be preserved.

The upstream root engine, native/JNI exploit chain and kernel-module implementation are intended to stay unmodified. Android app compatibility with SM-S918N has not been verified. Do not assume builds imply rooting compatibility.
